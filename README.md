# Podstawy_AI
skrypty z ćwiczeń

## Skrypty

- `filtr_gaussa.py` — wygładzanie obrazu filtrem Gaussa.
- `filtr_konwolucji.py` — konwolucja bez paddingu (stride=2) z filtrem wyostrzającym.
- `filtr_laplace.py` — wykrywanie krawędzi filtrem Laplace'a.
- `filtr_sobel_x.py` — detekcja krawędzi pionowych operatorem Sobel X.
- `filtr_sobel_y.py` — detekcja krawędzi poziomych operatorem Sobel Y.
- `filtr_wspolny.py` — funkcje pomocnicze do wczytywania, konwolucji i zapisu/wyświetlania obrazu.
- `filtr_wyostrzajacy.py` — wyostrzanie obrazu filtrem 3x3.
- `canny_edge_detection.py` — demonstracja detekcji krawędzi algorytmem Canny'ego.
- `probabilistyczna_transformacja_hougha.py` — wykrywanie linii probabilistyczną transformacją Hougha.
- `grabcut_wiewiorka_czarne_tlo.py` — segmentacja wiewiórki metodą GrabCut i zapis na czarnym tle.
- `wszystkie_filtry_wiewior.py` — uruchomienie wszystkich filtrów/detektorów i zapis wyników do osobnych plików.
